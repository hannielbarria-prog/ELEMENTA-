# ELEMENTA — Juego interactivo de Química

Primera versión basada en el informe del proyecto ELEMENTA.

## Cómo probarlo
1. Abre `index.html` en un navegador.
2. En celular, puedes abrirlo con un navegador o subir la carpeta a un servicio de alojamiento estático.
3. No necesita servidor ni base de datos para esta versión.

## Capacidad
Esta versión es un juego estático: cada jugador guarda su puntuación y descubrimientos en su propio navegador. Por eso, muchas personas pueden jugar simultáneamente sin que el sitio tenga que compartir una sesión.

Si se necesita un marcador global, cuentas de usuarios o partidas sincronizadas, habría que añadir un backend/base de datos.

## Archivos
- index.html — estructura
- style.css — diseño responsive
- script.js — lógica del juego
